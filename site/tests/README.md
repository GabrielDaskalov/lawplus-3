# Проверки

Автоматични проверки срещу истински сървър и истинска база. Не са unit
тестове — минават през браузър и правят това, което прави студентът.

## Какво проверява всяка

| файл | какво |
|---|---|
| `01-obikolka.mjs` | всичките 27 екрана се отварят; заключеното е заключено; въпросът не носи отговор; проверката минава през сървъра |
| `02-funkcionalno.mjs` | тест до края с резултат; въпроси по избрана задна тема; търсене; флашкарти; сесия след презареждане; изход |
| `03-admin.mjs` | ролята се разпознава; панелът чете от базата; редакция се записва в базата и оставя следа в журнала |
| `04-bez-survar.mjs` | при спрян backend витрината пак работи, а платените екрани казват ясно какво не е наред |
| `05-vizualno.mjs` | снимки на публичните екрани за сравнение с предишна версия (пиксел по пиксел) |
| `06-funkcii.mjs` | 13-те интерактивни функции: помодоро, изпитен жребий, план, бележки, тетрадка на грешките, SRS, постижения, AI асистент, Cmd+K, тема, настройки, поддръжка, отбелязване на тема |

## Пускане

```bash
# 1. Backend на 3000 (или друг порт) и база с миграция 010 + внесено съдържание
# 2. Сглобен сайт, сервиран заедно с /api:
npm run build
node serve.mjs dist          # http://localhost:8080

# 3. Проверките (искат работещ Chromium; пътят е в самите файлове)
node tests/01-obikolka.mjs
node tests/02-funkcionalno.mjs
node tests/03-admin.mjs
```
